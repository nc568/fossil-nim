⚡ 100% Pure Nim Архитектура

  • Myers Unified Diff: Оригинальный алгоритм построчного сравнения Майерса, скомпилированный из Nim в чистый JS.
  • Fossil Delta Compression: Скользящее окно совпадений и вычисление дельт манифестов репозитория.
  • Zero Bloat: Ни одного внешнего NPM пакета или тяжелого фреймворка, только нативные веб-стандарты.
  • QBE / Native совместимость: Идентичные структуры данных между нативным сервером и браузерной версией.

💾 3 Хранилища в Браузере

  • IndexedDB: Встроенная NoSQL база браузера с транзакциями, идеальна для долгосрочной локальной работы.
  • SQLite WASM: Настоящий SQLite 3.45 внутри WebAssembly с поддержкой двоичных .fossil репозиториев.
  • Pure-Nim CDB: Constant DB в оперативной памяти (RAM) для сверхбыстрых тестов и сессий ИИ-агентов.
  • Умный импорт/экспорт: Поддержка слияния (Merge) и полной замены (Clean Replace).
