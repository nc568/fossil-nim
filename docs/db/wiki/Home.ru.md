# Foccil DB — Вики

**EN:** [English wiki home](Home.md)

SQL-движок на Nim (ARC) для проекта Foccil-nim. Один исходник — три бэкенда: C, JS,
WebAssembly. Это не порт SQLite, а переписывание с вырезанным легаси.

## Коротко

```
Размер ядра        4 492 строк        (SQLite: ~150 000)
Тесты              26 core + 20 security + 17 storage + 18 WAL + 24 btree + 3 crash + 34 crypto + 10 corrupt
Паритет бэкендов   native == JS, байт в байт (md5 0376a7c4…)
wasm              328 КБ, без emscripten и wasi-sdk
Точечный поиск     185 842 запроса/с  (было 56 до планировщика индексов)
Главный открытый   сборка через cproc/QBE — блокер в апстриме, репродьюсер приложен
```

## Как запустить

```sh
sh tools/bootstrap.sh   # Nim, qbe, cproc, musl, zig в ~/.cache/tc
sh tools/test.sh        # гейт из 6 стадий
nim c -r -d:release --mm:arc tools/bench.nim
sh tools/wasm/build.sh && node tools/wasm/run.js
sh tools/cproc/check.sh # таблица совместимости
```

## Соглашения

* Значения попадают в SQL **только** параметрами. Без исключений.
* Функциональность без теста не считается сделанной.
* Документация обновляется на RU и EN в том же коммите, что и код.
* Любое изменение размера wasm или памяти на запрос сопровождается замером.
