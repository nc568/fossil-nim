# Веб-паритет 100% — 2026-10-17 финал

## Цель
Довести с ~95% до 100%: winfo blame, wdiff side-by-side, tinfo timeline, artifact hex, attach full, report custom SQL, sitemap dynamic.

## Реализовано

### 1. /winfo с blame
- `getWikiBlameSqlite` — все строки атрибутируются последнему пользователю (MVP)
- `renderWinfoPage(pageName, info, blame)` — метаданные RID/UUID/Date/User/Comment/Size/Tag, preview 2000, Actions View/Edit/History/Diff/Side-by-Side/Content by RID, Blame таблица #, User, Date, Content с htmlEscape

### 2. /wdiff с side-by-side
- `renderDiffSideBySide` в full_parity.nim — две колонки Old/New, line-add/del/context, lineno, кнопки Unified/Side-by-Side
- Handler: ?side=1 → side-by-side, иначе unified via diffMod.diffBlobs Myers

### 3. /tinfo с timeline
- `getTicketHistorySqlite` — SELECT из ticketchng WHERE tkt_id=?1, bind
- `renderTinfoPage` с history таблицей Date, User, Field badge, Comment

### 4. /artifact с hex dump
- `hexDumpBlob` — hexdump -C формат offset, hexPart, asciiPart
- `renderArtifactPage` — Metadata ID/Size/Type, Actions Raw/Download/Info, Hex Dump 4K или Content 10K
- Handler: ?txt=1 → HTML с hex, иначе binary download, secHeaders с CSP

### 5. /attach full
- `getAttachmentsSqlite` теперь chat_message + forum_post attachments, объединённый список

### 6. /report custom SQL
- `renderReportCustomPage` — SQL Query блок, Results table динамические колонки, error handling
- Handler: ?sql=SELECT... — только SELECT разрешён, выполняет через sqlite3_prepare_v2, column_count/name/text

### 7. /sitemap dynamic
- `renderSitemapDynamicPage` — группировка по первой части пути, badge, Total pages: 53
- Handler: 53 страницы (/, /timeline, /file, /finfo, /info, /diff, /blame, /tree, /brlist, /taglist, /leaves, /stat, /zip, /raw, /artifact, /wiki, /winfo, /whistory, /wdiff, /ticket, /tinfo, /report, /attach, /forum, /chat, /search, /rss, /login, /setup, /help, /sitemap, /bench, /api/v1/...)
