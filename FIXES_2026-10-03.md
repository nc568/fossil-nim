## 3-way Merge

- `vcs/merge.nim`: полностью переписан
  - `extractHunks` извлекает ханки из `diffBlobs`
  - `mergeHunks` мержит неконфликтующие ханки, сохраняет оба изменения
  - При конфликте — маркеры `<<<<<<< ours` / `=======` / `>>>>>>> theirs`
- Тест: base `line1,line2,line3`, ours меняет line2, theirs меняет line3 → merge сохраняет оба без конфликта; одновременное изменение одной строки → конфликт

Результат: merge больше не теряет данные

## Формат манифеста / zlib / дельта / mtime

- `artifact/manifest.nim`: `manifestToString` теперь вычисляет реальный SHA3 хеш для Z, а не `dummy-checksum`
- `storage/sqlite_backend.nim`: добавлены `compressBlob`/`decompressBlob` с 4-байтным BE заголовком и zlib (`compress2`/`uncompress`)
  - Если сжатие выгодно — хранит `4-byte origSize + compressed`, иначе `4-byte 0 + raw`
  - `getBlobRaw` декомпрессирует, поддерживает старый raw формат для совместимости
- `delta/delta.nim`: полностью переписан для Fossil-совместимости
  - Base64 алфавит `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ_abcdefghijklmnopqrstuvwxyz~` (MSB first)
  - `encodeInt`/`decodeInt`/`encodeIntU32`/`decodeIntU32`
  - `computeChecksum` — сумма BE 32-битных слов
  - `deltaEncode` теперь `size\n ops checksum;\n` с base64 числами
  - `deltaDecode` парсит base64
  - Пример `6246 → 1Xb` совпадает с Fossil spec
  - Roundtrip тест проходит
- `vcs/timeline.nim`: убраны фейковые данные, теперь получает реальный uuid из `blob` таблицы, обрабатывает Julian date (float) и Unix timestamp

Результат: репо более совместимо с оригинальным Fossil (Z реальный, блобы с zlib+4-byte header, дельта base64, mtime Julian)
